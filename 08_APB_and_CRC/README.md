# ЛР8 — APB и CRC

В данной лабораторной работе рассматривается подключение аппаратного вычислителя CRC к системной шине **APB**.

Основная цель работы — изучить принцип обмена данными по APB, реализовать вычислительный блок CRC по индивидуальному варианту и оформить для него APB-обёртку с регистровым интерфейсом.

## Описание работы

В лабораторной работе был доработан пример вычислителя CRC8 и реализован вычислитель **CRC16** для полинома:

```text
g(x) = x^16 + x^12 + x^5 + 1
```

Для подключения вычислителей к системной шине используется модуль-обёртка `wrapper_crc16`. Он принимает APB-сигналы, формирует управляющие сигналы для вычислительных блоков и возвращает результат вычисления через регистры чтения.

В проекте используются два вычислительных блока:

- `crc16` — вычисление CRC16 по индивидуальному варианту;
- `crc8` — базовый вычислитель CRC8 из примера лабораторной работы.

Выбор активного вычислительного блока выполняется через управляющий регистр `control_reg`.

## Регистровая карта

| Адрес | Доступ | Назначение |
|------:|:------:|------------|
| `0x0` | Write  | Запись входных данных для вычисления CRC |
| `0x4` | Read   | Чтение результата вычисления CRC |
| `0x8` | Read   | Чтение состояния конечного автомата |
| `0xC` | Read/Write | Управляющий регистр выбора вычислительного блока |

### Управляющий регистр

В текущей реализации используется младший бит `control_reg[0]`:

| Значение `control_reg[0]` | Выбранный блок |
|:-------------------------:|----------------|
| `0` | CRC16 |
| `1` | CRC8 |

## Состояния вычислителя

Оба вычислительных блока имеют конечный автомат со следующими состояниями:

| Код | Состояние | Описание |
|:---:|-----------|----------|
| `00` | `IDLE` | Ожидание новых данных или запроса чтения |
| `01` | `BUSY` | Выполнение вычисления CRC |
| `10` | `READ` | Чтение результата и очистка CRC-регистра |

## Особенности реализации

- Интерфейс обёртки построен на сигналах APB: `p_sel_i`, `p_enable_i`, `p_we_i`, `p_adr_i`, `p_dat_i`, `p_dat_o`, `p_ready`.
- Сигнал `p_slverr` не используется и постоянно равен `0`.
- Запись входных данных выполняется по адресу `0x0`.
- Чтение результата CRC выполняется по адресу `0x4`.
- Чтение состояния автомата выполняется по адресу `0x8`.
- Управляющий регистр доступен по адресу `0xC`.
- Для CRC8 результат расширяется до 16 бит при выдаче через общий выходной путь.
- Сигнал `p_ready` формируется через внутреннюю задержку acknowledge-сигналов.

## Моделирование

Для проверки работы написан testbench `tb_wrapper_crc16.sv`.

В ходе моделирования выполняются следующие действия:

1. Выполняется сброс схемы.
2. Через управляющий регистр выбирается режим CRC16.
3. В регистр данных записывается тестовое значение `0x0000_AAAA`.
4. После завершения вычисления считываются состояние автомата и результат CRC.
5. Через управляющий регистр выбирается режим CRC8.
6. В регистр данных записывается тестовое значение `0x0000_0033`.
7. Повторно считываются состояние автомата и результат CRC.
8. Дополнительно выполняется чтение по адресу `0x0`.

Для имитации APB-транзакций в testbench используются задачи:

- `write_register` — выполнение транзакции записи по APB;
- `read_register` — выполнение транзакции чтения по APB.

## Итог

В результате выполнения лабораторной работы был реализован APB-периферийный блок для вычисления CRC. В проект добавлен вычислитель CRC16 по индивидуальному варианту, управляющий регистр выбора вычислительного блока, регистр состояния автомата и testbench для проверки операций записи и чтения по APB.
